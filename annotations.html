Ta Kobo garde tout dans un fichier nommé KoboReader.sqlite. Donne-le à cette page : elle le lit sur ton appareil, rien n’est envoyé ailleurs.

  1. Branche ta Kobo à ton ordinateur avec le câble USB, puis touche Connecter sur l’écran de la liseuse.
  2. Ouvre le disque KOBOeReader, puis le dossier caché .kobo. Sur Mac, appuie sur Cmd + Maj + . pour voir les dossiers cachés. Sur Windows, coche Éléments masqués dans l’onglet Affichage.
  3. Dépose le fichier KoboReader.sqlite ci-dessous.
